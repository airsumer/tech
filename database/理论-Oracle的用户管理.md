

# 用户

`sys`是Oracle最高权限的用户，不允许直接以普通用户身份登录。如

``` bash
sqlplus sys
```

会报错。要登录sys用户，必须指明要用的权限。可以使用两种特权身份登录。

## `SYSDBA` vs `SYSOPER` —— 两种特权身份

| 身份          | 权限范围                                                     | 典型用途                         |
| ------------- | ------------------------------------------------------------ | -------------------------------- |
| **`SYSDBA`**  | 最高权限： • 启动/关闭数据库 • 创建/删除数据库 • 访问所有用户数据 • 修改数据字典 | 数据库安装、升级、灾难恢复       |
| **`SYSOPER`** | 有限管理权限： • 启动/关闭数据库 • 执行备份恢复 • **不能访问用户数据** • **不能修改数据字典** | 日常运维（如启停、备份），更安全 |

如：

``` bash
$sqlplus sys/password@//192.168.1.100:1521/ORCLPDB1 as sysdba
```



三种用户

sys：超级管理员

system：系统管理员

普通用户
